# Nota sobre la colección Postman

La colección CONDORIISABEL-H2T9.json ya está incluida en la rama feature/api. Para usarla en Postman:

1. Abre Postman -> Import -> selecciona CONDORIISABEL-H2T9.json
2. Crea un Environment con la variable base_url = http://localhost:5000
3. Ejecuta las peticiones una a una o en conjunto.
